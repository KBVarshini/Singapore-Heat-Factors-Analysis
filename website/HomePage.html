Project Description

The goal of this project is to develop a footfall sensor that can detect foot traffic, specifically for vending machines. We are to make use of data analysis techniques to gain insights from the collected data from the sensor and understand the relationship between foot traffic and its impact on sales in Singapore.

Additionally, there is a need to collect Land Surface Temperature (LST), Weather data using Google Earth Engine, Population Density using OpenStreetMap, Vegetation Cover data using Google Earth Engine, Crime Rates and Hawker Centre data.. This requires writing the code in both Python and JavaScript, by integrating with AWS.

All the data collected is to be stored Amazon S3 in AWS. Lastly, all the gathered data is to be visualized, by creating a user-friendly interface, which is this website, that can be easily understood by non-technical users. It is important to present the data in a clear and organized manner, ensuring that users can understand it easily. Based on all the data collected, the client will decide where to sell his sugarcane drinks.

Task Description

Task 1: Gather Population Density data for the subzones of Singapore using OpenStreetMap and Nominatim API. This involves in writing the code to display the data on the map. The script is firstly to be written in Python and then JavaScript. The map will then be displayed on this website as part of visuazlization.

Task 2:Gather Vegetation Cover data all around Singapore, using LandSat 8 satellite, via Google Earth Engine. This involves writing the JavaScript code and then publishing my code as an application onto internet. In this case, anyone can access the Vegetation Cover map.
